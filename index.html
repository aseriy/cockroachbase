Build your application with less backend work

CockroachBase brings familiar application services to CockroachDB, helping you ship sooner, lower development costs and keep control of what you build.

Like Supabase, CockroachBase is an application platform: it connects the services your application needs. CockroachDB is the database underneath, storing your data and providing the distributed foundation for growth.

Start with a deployment that fits your budget. Build toward enterprise scale and a global audience.

Your application’s building blocks, connected

CockroachBase reduces the assembly and integration work between essential services:

  • Data APIs let your frontend and application logic read and write data.
  • Authentication handles user identity, sign-in and sessions.
  • Realtime helps your application respond to relevant data changes.
  • Storage holds application files and generated content.
  • Edge functions run custom server-side logic and connect external services.

You build and own the frontend, business logic, integrations and application-specific behavior. CockroachBase provides the services behind that experience; its management interface helps you operate them.

Bring the development patterns you know

Put your Supabase experience to work with familiar API and SDK interactions in JavaScript, TypeScript and Python.

Query and update data, call SQL functions through RPC, manage authentication, subscribe to changes, work with storage and invoke functions. Familiar patterns shorten the learning curve while CockroachDB gives your application a distributed database foundation.

Connect live applications and AI workflows

Build live applications, reporting interfaces, event-driven enrichment, semantic search and your own AI workflows and agents on connected data and application services.

A data change starts processing. Your logic reads context, calls external services or models, and saves results and processing state. The frontend and other services then respond to the outcome.

CockroachBase supplies the foundation. You supply prompts, tool integrations, business decisions and agent execution, extending behavior through edge functions and external processing.

For semantic retrieval, combine embeddings with relational application data. CockroachDB’s distributed vector indexing is designed to shard and rebalance as data grows; your application or external services generate embeddings and execute models. :chatgpt-content-reference{index="0"}

Choose a deployment that fits your economics

CockroachBase connects to CockroachDB through a database connection string and supports Serverless, Advanced, Continuum, BYOC and self-hosted deployments. Choose the operating model that suits your application and team.

Start small

Start small with managed infrastructure

Keep initial commitment low with a small managed workload and usage-based billing. Eligible existing Basic deployments, previously called Serverless, retain their monthly free resource allowance. New deployments use Continuum pricing, with a 30-day, $400 trial for new Cloud organizations. Legacy Basic and Advanced pricing applies to qualifying deployments created before September 15, 2026 and is no longer sold for new deployments. :chatgpt-content-reference{index="1"}

Existing capacity

Put existing capacity to work

Continuum Virtual Clusters, in public preview, let smaller, occasional and bursty workloads share existing database infrastructure with workload isolation. Better utilization can lower the incremental cost of another application while consolidating operations. Shared host, storage and applicable service charges still apply. :chatgpt-content-reference{index="2"}

Self-host

Self-host with no database license fee if eligible

CockroachDB Enterprise Free provides the same Enterprise database functionality to eligible organizations with less than $10 million in combined annual revenue, including parents and affiliates. Infrastructure and operating costs remain separate. Annual license renewal and telemetry are required. See eligibility. :chatgpt-content-reference{index="3"}

Dedicated

Match demanding applications to dedicated resources

Supported Advanced deployments combine dedicated managed resources, multi-region deployment and security controls. For new purchases, Continuum Mission Critical provides the dedicated infrastructure option. :chatgpt-content-reference{index="4"}

BYOC

Run managed CockroachDB in your own cloud account

BYOC keeps database infrastructure within your cloud account, aligning with your cloud boundaries, infrastructure spending and commercial commitments. Cockroach Labs manages database infrastructure operations under a shared-responsibility model.

Budget separately for CockroachBase, database services, hosting, storage and network usage, and external model or API services.

Grow on the foundation you start with

CockroachDB brings capabilities that become increasingly valuable as your application grows:

Scale with less application-managed sharding. Data is automatically split, distributed and rebalanced across nodes. Distributed ACID transactions, with serializable isolation by default, preserve transactional guarantees across that data.

Expand geographically and support continuity. Table- and row-level locality controls help place data around users, access patterns and regional requirements. Replication and automatic recovery support resilience within your chosen topology and survival configuration.

Keep improving a running application. Supported schema changes run in the background while the database serves traffic. MVCC retains data versions for consistent historical reads within the configured history window, helping reporting and investigation. :chatgpt-content-reference{index="8"}

Turn database changes into application behavior. Native changefeeds support integrations, enrichment and downstream processing beyond the Realtime interface. Configurable before-and-after values help your logic determine what changed.

CockroachBase’s end-to-end regional-resilience design targets are zero RPO and near-zero RTO: avoiding data loss and minimizing recovery time. Actual resilience depends on database topology, regional survival settings and the complete application deployment.

Keep ownership as your application evolves

As you grow, the same technology foundation can support greater scale and geographic expansion. Familiar APIs are the starting experience; CockroachDB’s deeper capabilities provide a path toward richer CockroachBase functionality.
